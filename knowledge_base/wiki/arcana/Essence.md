# [Arcana] Essence

**来源**: Arcana Wiki | **链接**: https://starboundarcana.miraheze.org/wiki/Essence

---

Essence is a fundamental crafting component used in many recipes. They can be obtained in various ways: using an Essence Extractor, defeating Monsters or Bosses, mining ores, and smashing pots in Corridors. 

| Icon | Name | Acquisition |
| --- | --- | --- |
| | Magiflux Extract | Extracted from Arcane Water or [Healing Water](https://starbounder.org/Healing_Water). |
| | Ice Essence | Extracted from Illuminated Water, Ruinous Water, or [Liquid Erchius Fuel](https://starbounder.org/Liquid_Erchius_Fuel). |
| | Fire Essence | Extracted from [Lava](https://starbounder.org/Lava). |
| | Poison Essence | Extracted from [Poison](https://starbounder.org/Poison). |
| | Electric Essence | Extracted from Neon Water or [Liquid Erchius Fuel](https://starbounder.org/Liquid_Erchius_Fuel). |
| | Lunar Essence | Defeating Dheral or from smashing pots in Lunar Corridors. |
| | Solar Essence | Defeating the Solar Guardian or smashing pots in Solar Corridors. |
| | Vermilion Essence | Defeating Vermilion Golems or mining Aspirite Ore. |
| | Anima Essence | Mining Immorite Ore. |
| | Aeon Essence | Defeating the Aeon Timepiece. |
| | Azure Essence | Defeating Azure Golems. |
| | Light Essence | Defeating Trispiels. |
