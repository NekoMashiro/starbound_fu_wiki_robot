Consumable Items / Summoning Items / Evo Abomination

## Overview
The Evo Abomination is an item that can be used to conjure the first boss of Arcana, Evolapis. It can be crafted at an Academician's Table. 

Note, the Evo Abomination can only be used on an Evoaquatic planet.
