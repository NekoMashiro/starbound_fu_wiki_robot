Ores / Immorite Ore

## Overview
Immorite Ore is an ore that can be mined on Planets orbiting Tripolar Stars. It is always found in the fir underground layer, in medium sized chunks. Anima Essence can be found in the ore chunks as well.

## Usages
Aspirite ore can be refined at an Auric Smelter using 2 ore and 1 Anima Essence. It can be used for crafting one set of armor, a few augments, and Nullatus Bar.
