Ores / Noxion Ore

## Overview
Noxion Ore is an ore that can be mined on Planets orbiting Tripolar Stars. It is always found in the second underground layer, in medium sized chunks. Poison Essence can be found in the ore chunks as well.

## Usages
Noxion ore can be refined at an Auric Smelter using 2 ore and 1 Poison Essence. It can be used for crafting one set of armor, a few augments, and Nullatus Bar.
