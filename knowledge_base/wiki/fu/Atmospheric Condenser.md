# [FU] Atmospheric Condenser

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Atmospheric_Condenser

---

**Atmospheric Condenser** is a device that obtains resources out of thin air. When powered, it produces 1 random item every 2 seconds (each time this happens, 50J of energy is consumed).

Possible results (which items are produced) depend on type of the planet (see below). If some planet is not listed below, then it uses the "normal planets" list.

It is a more advanced version of Liquid Collector (which could only generate biome-specific liquids), but it will collect less liquid than Liquid Collector would.

Atmospheric Condenser works both on spacestations and on player's ship. Furthermore, when a player's ship is orbiting some planet, the type of that planet is what determines the results (e.g. you'll get Lava while orbiting an Infernus planet).

If there are other "air wells" (Liquid Collectors, Atmospheric Condensers or Entropic Converters) within 20 blocks, then Atmospheric Condenser will have significantly reduced production. Scan the Atmospheric Condenser to check if it was affected by this.
