# [FU] Extraction Lab

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Extraction_Lab

---

**Extraction Lab** is an early-game extractor. It has the same outputs as Hand Mill, but is faster, has more slots and requires Power.

Extraction Lab does 1 extraction every 4.75 seconds. Later in the game it gets replaced by Extraction Lab MKII, which is even faster. MKII is also more efficient when extracting some (but not all) input materials.
