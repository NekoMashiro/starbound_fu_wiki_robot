**Apex Test Chamber** is an Apex themed dungeon that was sometimes found beneath an **Apex Research Lab**. The dungeon has a set of parkour-like challenges that mainly used Tesla Spikes and Poison as obstacles.

At the end of the dungeon is a High-Tech Chest.
