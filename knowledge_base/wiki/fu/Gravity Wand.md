# [FU] Gravity Wand

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Gravity_Wand

---

**Gravity Wand** is a 1-handed tool that allows you to fly for up to 60 seconds.

After you activate it, any movable object that comes near the cursor (including the player, NPCs, monsters, pets, etc.) will continue moving with the cursor. This movement is unopposed by gravity, so you can either fly up or descend at a safe speed.

Warning: rapidly moving a cursor too far from an object (including the player) will cause Gravity Wand to lose its "grip" on it. Move the cursor slowly if you don't want to fall.
