# [FU] Greenfinger Medal

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Greenfinger_Medal

---

An item given as a reward at the end of The Verdant Ruins. You can give it to the Meat Shop owner in the quest **Ssad losst thingss** for a Friendship Mask. It can be researched for Protheon and Research, so make sure you do so before giving it away. It has no other usages beyond this.
