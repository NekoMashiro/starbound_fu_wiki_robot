# [FU] Hoe

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Hoe

---

**Hoe** is the most basic tool for tilling soil blocks (such as Dirt), which allows you to plant seeds on them.

Later in the game it can be replaced with a better Hand Hoe or superior Harvester Beamgun. You can also till blocks by throwing a Tinselbush Dart.
