# [FU] Holiday Spirit

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Holiday_Spirit

---

**Holiday Spirit** is unused item unless you have Frackin Xmas (an optional separate mod, which is meant to be installed before Christmas and uninstalled afterwards). If you have that mod, Holiday Spirit becomes a random drop from monsters, etc.

This item has no use other than extracting into 1-3 pixels and buying decorations, so if you don't want to deal with this resource, simply don't install Frackin Xmas.
