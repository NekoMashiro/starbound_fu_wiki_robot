# [FU] Incinerator

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Incinerator

---

> *This is a page about **placeable object**. For flamethrower called Incinerator, see Incinerator (weapon).*

**Incinerator** is a 1-slot storage. It immediately destroys any item that you place inside. Destroyed items are not recoverable later.

It can be used with Item Transference Device to throw away resources that you somehow produce, but don't need.

## Alternatives
- If you need to dispose of too many items, you can use Mass Incinerator (which has 64 slots).
- Another option is Terramart Shipments 3.0, which has only 40 slots, but will sell the items instead of destroying them.
