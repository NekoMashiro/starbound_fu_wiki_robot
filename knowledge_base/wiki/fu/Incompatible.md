# [FU] Incompatible

**来源**: Frackin' Universe Wiki | **分类**: Everything | **链接**: https://frackinuniverse.miraheze.org/wiki/Incompatible

---

Please note that while this list is frequently updated, it is by no means a be all to end all of incompatible mods. There could be some we have missed. If adding to this list please use the exact name of the mod, and only add mods if you've confirmed them to have issues on an otherwise-compatible setup.

This list is not focused on balancing problems. Only bugs and crashes.

You may also want to check our mod recommendations for mods that should play nice with FU.

### Already included
Installing included mods can either have no effect, adds duplicates, cause unintended behavior, or crash.
View the list here.

### FU Translation Mods / Language Translation Mods
Don't use them. None can keep up with us, and almost all are completely outdated or incompatible due to script-related issues. They are not recommended and we will not help you debug them.

### Frackin' Races
You don't need this if you're using FU. It's now included, and your game won't function if you have both installed.

### zTarbound
This mod started in FU and has always been included with it. Don't install it alongside FU, it will break things!

### Potential Issues
- Aimable Shields - All FU shields are already aimable
- Any race extender - FU contains one already which supports up to 100 races, you probably won't need an external extend.
- Armor Augments - causes Armorworks to not show some information (e.g. tier of armor)
- Augment Extractor - Already included in FU (provided by original author)
- Classical Weaponry - Partially included in FU, and may break rapiers or other weapons.
- Customizable Shuttlecraft - Certain FU weapons will break the shuttlecraft controller when installed. It is impossible to fix the bugged controller, and as long as it is in your inventory, it renders all other vehicles irreparable. Also, FU has its own, much better balanced flying vehicles.
- Damage Cap Begone - Messes with damage scaling, and FU already does this.
- Earths Finest: Crew Improvements - FU includes most of these changes
- Enable Monster Special Attacks - FU Already does this.
- guns but they do the thing when no gravity - Breaks FU reload mechanic, reverting weapons to energy use only.
- Keep Your Day Job - Causes furniture tags to be ignored, breaking tenant spawning.
- Mech Detallist - Breaks Mech Repair Tool and Mech Repair Pod.
- Non-Uniform - Works fine, but your crew will sometimes be nude
- Pixel Furnishing 2.0 - Duplicate "lumothlamp" object
- Real Ferozium (Enemey Mechs) - Tossup on whether enemies in mechs spawn right or glitch out. Reloading the space (leaving and come back) fixes the issue but can be annoying none the less.
- Some mods that globally modify light - May break light sensors in tile-protected areas. Also note that all dungeons were made with vanilla illumination in mind, and may look very weird with mods that make it brighter/dimmer.
- Tsaiqir Race - Breaks FU Configure Ship Pet mechanic
- Vanta Race - Duplicate assets from the old Nightar mod

### Risky, avoid
- Mods that replace SAILs such as A.B.A.T.H.U.R or A.V.I.A.N - May break SAIL. If you insist on changing SAIL, install one that only changes the portrait of the SAIL and nothing else.
- Armor Adapt - makes it impossible to upgrade armor in Tricorder
- Atmosphere Plus - Breaks starting system generation (Moons, Deserts and Forests are not guaranteed), which may result in an inability to obtain necessary materials.
- BYOS (BuildYourOwnShip) - FU already contains a BYOS system.
- Draconis FU Addon - Outdated. Breaks things.
- Faster Start - Frackin' BYOS requires tungsten in your starting system to repair your FTL drive. Using the mod may result in no Moons, Forests, or Deserts spawning, leading to a lack of vital resources.
- FrackinUniverse Ground Seeders - Outdated, and FU already contains a more powerful tool to perform the same function.
- Improved Containers - Outdated mod. Use Enhanced Storage instead.
- Legacy Fuels - Duplicate plutonium issue
- Madtulips Mod - FU already contains a BYOS system
- Named Saplings - FU makes similar changes, and NS can't handle saplings crafted in the greenhouse.
- Planets generation Overhaul - Conflicting changes to planet sizes, etc.
- Quiet Crafting Stations - Breaks scripts on Sewing Machine, causes client crash when attempting to upgrade to Clothing Fabricator.
- RealisticFURecipes - Not updated frequently enough, and is very likely not up-to-date.
- Swansong Mech Parts - Breaks mech parts.
- Tier 9/Tier 10 ships - Breaks BYOS
- TrueSpace - Some FU planets become too rare. Breaks starting system generation (Moons, Deserts and Forests are not guaranteed), which may result in an inability to obtain necessary materials. Partially fixed by [this patch](https://steamcommunity.com/sharedfiles/filedetails/?id=3378807338), but is still not recommended.
- Very Varied Vehicles - Outdated, breaks vehicles.
