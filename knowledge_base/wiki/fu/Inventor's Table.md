# [FU] Inventor's Table

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Inventor's_Table

---

> **Attention, new players:** if your Inventor's Table is EMPTY, see **Research** - that page will explain everything!

**Inventor's Table** is used to make other crafting stations. It's crafted initially using player's bare hands, and later can be upgraded twice (to Engineer's Table, and then to Architect's Table).

In Frackin' Universe, this vanilla Crafting Station has new items to craft.
