# [FU] Invisible Tile

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Invisible_Tile

---

**Invisible Tile** is a decorative block that is completely invisible when *painted* (it looks as if there isn't any block in the location where it was placed). You can walk or build on top of it.

Despite looking like thin air, Invisible Tile is very sturdy: it has 50 hitpoints (second only to the Diamond Block, which has 84). This can be useful for protection against harmful weather.

## How it works
- When placed, this block won't appear to be completely invisible, but it immediately turns invisible if you Paint it (with Paint Mode of your Matter Manipulator), regardless of which color you use.
- To make this block visible again, use Paint Mode to remove the paint.
- Being invisible means that this block shows background of the current biome. If you terraform a planet like Ocean (which will change the biome, but won't affect the liquid), and then place Invisible Tile underwater, then Invisible Tile won't look like the ocean liquid, and therefore wouldn't be completely invisible.
