# [FU] Item pages with broken automatic infobox

**来源**: Frackin' Universe Wiki | **分类**: Pages with problems | **链接**: https://frackinuniverse.miraheze.org/wiki/Category:Item_pages_with_broken_automatic_infobox

---

This category is automatically populated with pages where Template:Automatic infobox item couldn't find the item in the Cargo database. This can sometimes help to track/troubleshoot errors.
> This can happen:
> # when two items have the same name, but the bot couldn't generate unique page names for both,
> # when some item was renamed or removed in-game,
> # ... for other unforeseen reasons.

Note to admins: **don't delete this category** even if it's currently empty.
