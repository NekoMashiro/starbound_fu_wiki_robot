# [FU] Items by colony tag

**来源**: Frackin' Universe Wiki | **分类**: Items by various parameters | **链接**: https://frackinuniverse.miraheze.org/wiki/Category:Items_by_colony_tag

---

Every furniture has some tags. They affect the type of tenant that will be summoned in the room with this furniture. You can use Object Data Sensor to see the tags of placed objects.
