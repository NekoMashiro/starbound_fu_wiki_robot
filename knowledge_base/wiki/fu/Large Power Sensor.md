# [FU] Large Power Sensor

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Large_Power_Sensor

---

**Large Power Sensor** can be wired to power-related objects (generators, Power Relays, stations that consume power, etc.), and will show available Power in the entire network (not just in the object it is wired to). It can display numbers from 0W to 9999W. Value "!!!!" means "10000W or more".

"Available power" means the difference between ALL produced power (by all generators) and ALL spent power (by all machinery). Presence of the batteries doesn't matter for the Power Sensor, because they don't have a Watt limit (they output as many Joules as the machinery needs).

There is a more compact Power Sensor that only displays 1 digit (from 0W to 9W).
