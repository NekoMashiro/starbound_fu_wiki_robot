# [FU] Liquid Mover Input

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Liquid_Mover_Input

---

**Liquid Mover Input** is a part of Liquid Network. It sucks the liquid around itself (similarly to Drain), but instead of throwing it away (like Drain does) it sends the liquid to other Liquid Mover Pump or Pressurized Mover Pump, which must be connected to the wire of Liquid Mover Input.

If its output is not connected to anything, or if Liquid Mover Pump doesn't have enough space to pour the liquid, then Liquid Mover Input won't do anything.

Additionally you can enable/disable the Liquid Mover Input by connecting its to Iron Lever (or any other button/switch).
