# [FU] Liquid Mover Pump

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Liquid_Mover_Pump

---

**Liquid Mover Pump** is a part of Liquid Network. When it is wired to a Liquid Mover Input, it will receive liquid from it and immediately pour this liquid into the world.

If there isn't enough space to pour the liquid to, then Liquid Mover Pump will do nothing. It won't make Liquid Mover Input drain any liquid unless this liquid can be reliably poured.

## Alternatives
- Pressurized Mover Pump - also pours the liquids, but doesn't stop even if there isn't enough space.
