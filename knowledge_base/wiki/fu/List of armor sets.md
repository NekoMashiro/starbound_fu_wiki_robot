# [FU] List of armor sets

**来源**: Frackin' Universe Wiki | **分类**: Armor, Items by various parameters | **链接**: https://frackinuniverse.miraheze.org/wiki/List_of_armor_sets

---

Frackin' Universe adds much more armour variety, with a number of sets for each tier in the game, all the way to Tier 8. Each armour set has its own playstyle, pros, and cons, and all armour sets can be upgraded through the tricorder interface, allowing you to use any set of armour for as long as you want. It's useful to have multiple sets of armour in order to adjust to the environment you're exploring or the activity you're doing.
