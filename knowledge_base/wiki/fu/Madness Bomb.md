# [FU] Madness Bomb

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Madness_Bomb

---

**Madness Bomb** is a grenade that can be thrown at monsters to make them attack each other.

They will still be hostile towards the player. If a monster is already chasing you, you might need to run away from it, so that it would choose to attack someone else.

This effect works on worm-like enemies like Doomwyrm, making their segments attack each other.
