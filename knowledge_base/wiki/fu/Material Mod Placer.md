# [FU] Material Mod Placer

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Material_Mod_Placer

---

The **Material Mod Placer** allows player to add decorative modifiers to blocks (grass, ash, people goo, etc.), as well as Ores, Accelerator Gel, etc.

This is mainly used for decorative purposes (adding grass to placed blocks, etc.), but can also be used to increase the hitpoints of blocks to help them resist damaging weather like Cosmic Blasts. An alternative to the latter is to use extremely sturdy blocks (such as Diamond Block) or a Field Generator. Adding Densinium Ore to the block adds 62 hitpoints to it.

## How to use
First, Shift+click to configure this tool ("which modifier to place?" menu).

Then click on blocks (right-click for background) to apply it.

## Eraser mode
"Change Mode" (mentioned in the tooltip) means that Material Mod Placer will be removing modifiers instead of adding them.

## Weather Protection
This tool can add invisible "weather protection" to blocks. It will protect them from being visually "dirtied" by weathers like snow, Bio Rain (weather on Bog planets that adds Algae to any blocks it falls upon), Blood Rain, etc.

This is for cosmetic purposes only: weather protection won't protect the blocks from being destroyed by damaging weather.
