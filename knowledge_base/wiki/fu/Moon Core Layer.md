# [FU] Moon Core Layer

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Moon_Core_Layer

---

**Moon Core** (also known as "dead core") is the lowest layer of moons. It doesn't have any core oceans (there is no Lava and no Core Fragments).

The bottom of this biome is composed of superhard Dead Core Blocks (you can mine them, which takes forever but is possible). There is nothing below them.
