# [FU] Pixel Printer

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Pixel_Printer

---

**Pixel Printer** allows you to craft objects (furniture, lights, chests) by spending pixels (instead of resources), but only if you **scanned** this object before. Things that you haven't scanned will not appear in the Pixel Printer.

Some items are not printable (for example, all crafting stations, as well as objects that you can craft elsewhere for resources).

## Precursor Fabricator
Precursor Fabricator is the decorative variant of Pixel Printer. It works exactly the same.
