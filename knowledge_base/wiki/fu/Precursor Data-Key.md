# [FU] Precursor Data-Key

**来源**: Frackin' Universe Wiki | **分类**: Precursor, Imported | **链接**: https://frackinuniverse.miraheze.org/wiki/Precursor_Data-Key

---

**Precursor Data-Key** is a quest item that is found very early in the Precursor Ruins mission (in the very first chest). You only need it once. When you pick it up, you get a SAIL mission "visit Precursor Ruins" (this permits you to later revisit this mission any time you want via SAIL, as with any other SAIL mission).

- **Description:** Unknown coordinates are stashed on this!
- **Quest Title:** A Strange Place
- **Text:** Where am I? This **data-disc** at least presents the coordinates. What is odd, is that this sector has always been devoid of...everything. I've gone ahead and **marked these coordinates** into my SAIL. I can return here later if need-be.

## Other uses
- If you have it in your inventory, then Void-Warp Locus (teleport staff) will work on Science Outpost.
- It can turn on/off the following buttons (they can't be pressed by hand): Tiny Keyed Button and Tiny Keyed Switch. Select Precursor Data-Key, point it at Tiny Keyed Button and left-click. The key is not consumed (can be used again later).
- : These buttons are not used in any mission secrets, etc., so you don't need the Precursor Data-Key to get any loot.
- : You can use these in multiplayer to create a wired button that only you know how to press. Even if another player knows that this button is not broken and just needs a key, they will likely not have a Precursor Data-Key in their inventory (it's useless 99,9% of the time, so why would they carry it?).
