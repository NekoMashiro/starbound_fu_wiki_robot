# [FU] Precursor Spawner

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Precursor_Spawner

---

**Precursor Spawner** is a device that spits out hostile monsters. The type of monsters is determined by contents of Capture Pod that you place inside the spawner. Non-capturable monsters are not spawnable.

Creation of each monster consumes some Beer (which is used as fuel). When the monster is defeated, approximately the same amount of Beer spills back to the ground. That might suggest that these monsters are actually made from Beer.

## Limitations
These monsters don't drop anything (even brains) except fake Skittles. Therefore the Spawner normally can't be used for farming. However, the Warped Regulator can apply certain (de-)buffs that cause additional currency (like Pixels and Ancient Essence) to drop. This also works for monsters spawned by the Precursor Spawner. Also, these monsters can be captured, so you can use the Spawner to obtain multiple Capture Pods with the same monster type.

Precursor Spawner can be placed into Warped Regulator, and this combination can be used for monster farming.
