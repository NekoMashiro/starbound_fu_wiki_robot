# [FU] Rock Crusher

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Rock_Crusher

---

**Rock Crusher** is a station that destroys stone-like blocks (like Cobblestone, Limestone, Meteorite Rock, etc.) and returns any useful materials that were hiding inside these rocks. Most blocks cost 0 pixels, and the materials within them can be very valuable, so this is very beneficial to do.

Rock Crusher processes 1 block every 0.25 seconds. It is a faster and more efficient version of the early-game Rock Breaker.

Sifter and Powder Sifter can process powder-like blocks in a similar manner.
