# [FU] Tinselbush Dart

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Tinselbush_Dart

---

**Tinselbush Dart** is a throwable weapon.

## Use in agriculture
When thrown at the ground, this dart makes any block (even Cobblestone, Hull Panel, Asphalt, etc.) suitable for planting the seeds (such as Corn Seed).

Normally only the flowers would be able to grow on these blocks, but Tinselbush Dart makes these blocks properly "tilled" (same as what Hoe does to Dirt and other normal soils), and this allows any plant to grow there.
