# [FU] Warped Regulator

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Warped_Regulator

---

**Warped Regulator** is an advanced version of Modified Pillar. It is a 3-slot storage, and depending on the items placed into it, all enemies within 500 blocks of it will be affected by various debuffs.

It is tremendously useful for certain tasks (like hunting monsters near the player's base), but crafting it requires both Elder artifacts (Valtan Casing) and high-tech Madness items (Anti-Neutronium Rod). Its power requirements are also very high (320W). However, once a player can afford it, it's a very worthwhile building to have.

## All effects
Below is a list of every item that has some kind of effect when placed inside of the Warped Regulator. Up to 3 of these effects can be achieved at once using one Regulator, by placing one of each item in each slot.

Stacking multiple of the same debuff is not possible. Likewise, putting multiple of the same item in the same slot also does not increase the effect. *(Needs testing)*
