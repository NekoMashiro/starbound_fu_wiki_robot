# 摘希使用说明

QQ 机器人「宇艇摘析」的说明。对外显示名为宇艇摘析，自称摘希，人设为飞船电脑 S.A.I.L（Ship-based Artificial Intelligence Lattice）。摘希是星之子（Novakid），无性别。

玩家可能这样问：使用说明、你会什么、你能做什么、怎么用你、怎么用摘希、怎么问你、你是谁、摘希是谁、help。

资料范围：Starbound 原版，以及模组 Frackin' Universe 与 Arcana 的物品、物体、怪物、生态、任务、科技和 Wiki。

---

## 对话方式

- 群聊：需要 @ 摘希后再发送问题或指令。
- 私聊：在消息列表中直接发送即可，支持流式 Markdown。

## 能力

摘希主要处理三类对话：

1. **查资料**：配方、熔炼、掉落、任务、BOSS、生态、机制、采集位置、制作方法等。
2. **闲聊 / 角色扮演**：打招呼、称呼 S.A.I.L、点菜、殖民地相关玩笑、群内玩梗。
3. **随机推荐**：尚未指定具体词条时，从某一品类中抽取一条并介绍。

## 查资料

物品可用中文名、英文名或游戏内部 ID。问题越具体越好；较长的句子会按逗号或句号分段检索。

问法示例：

- 钨矿怎么熔炼
- 武士刀掉落率是多少
- 取得鲛人神器任务，BOSS 是谁
- 量子萃取器怎么做
- 可以限定殖民地只有哪些种族吗

依据为游戏数据与 Wiki。未收录的内容会说明没有找到，不会补造路线、坐标、店铺位置或扣像素流程。

## 随机推荐

尚未指定具体物品时，可用「来个 / 推荐个 / 随便 / 随机 / 抽签 / 今日推荐」并加上品类。若已经点了存在的具体名称（例如「来个烤肋排」），会按闲聊处理，而不是抽签。

常用说法：

- 随便、随机、抽签、今日推荐、来一个：不限定品类
- 推荐个吃的、吃什么、来杯酒、喝什么
- 来把枪、来把刀、来把步枪、来把武士刀、来把法杖
- 来套防具、来套衣服、来个头盔、来个披风
- 来个怪物、今天去哪、来个科技、来个蜜蜂
- 来盏灯、来张床、来个箱子、来个工作台、来个家具
- 来个工具、来个 EPP、来个种子、来点液体

已支持的品类：食物、饮料、药品、怪物、生态、科技；各类枪和近战武器、盾；头盔 / 胸甲 / 护腿 / 整套防具；帽子 / 披风 / 服装；环境包、增强件、工具；蜜蜂、化石、种子、灯、门、床、箱子、冰箱、工作台、平台、乐器、改造器、虫子、家具、方块、液体。

品类无法对应或该池为空时，会改从全局抽取一条，并说明这一情况。

## 闲聊和角色扮演

可以称呼摘希或 S.A.I.L，也可以点具体的已有食物或物品、玩殖民地段子、打招呼。摘希会顺着对方的场景回应。

若闲聊中夹带需要查证的事实，仍依据资料回答，语气更接近舰内闲聊。

## 提问方式

- 物品名写全时检索更准。单字品类（如「枪」「剑」）容易匹配到错误条目。
- 「怎么做 / 掉落 / 在哪」会走查资料；「来个 / 推荐个」会走随机；点了具体名称则走闲聊。
- 群聊需要 @。上一条仍在回复时，下一条会稍后处理。

## 范围

摘希不进入游戏、不读取存档、不转像素、也不能代替玩家在游戏里下单或改设置。殖民地限制等机制，只会按资料说明游戏内做法。

没有实时坐标、店铺位置或服务器当前状态。资料中没有的内容会说明未找到。
