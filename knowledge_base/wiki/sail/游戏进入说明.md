# 游戏进入说明

本群 Starbound 联机服的进服资料。玩家可能这样问：怎么进服、服务器地址、端口多少、怎么下载、OpenStarbound、能不能用 Steam、用户名密码、难度怎么选、会不会饿死、死亡掉不掉东西、硬核、UI 太小、界面缩放、赛博灯泡、吞灯泡、Linux、Mac、捏人、种族、通过ip、资源不匹配、前景背景、按键、物品栏、丢东西。

本服使用群文件中的 **OpenStarbound** 整合包。Steam 商店版 Starbound 无法完整加载本服模组。

---

## 客户端

整合包文件名为 **OpenStarbound.zip**，在群文件中下载。解压后请保持目录结构完整。

Windows 启动文件位于：

`OpenStarbound/win/starbound.exe`

在资源管理器中进入该文件夹，双击 `starbound.exe` 即可启动。

## 与 Steam 的关系

整合包基于 **OpenStarbound**，与 Steam 版 Starbound 不是同一套运行环境。本服模组已包含在整合包内；从 Steam 库启动 Starbound 时，部分模组不会生效。已购买或订阅 Steam 版的玩家，进服时仍使用整合包中的 `starbound.exe`。

OpenStarbound 会读取 Steam 已订阅的 Starbound 创意工坊模组。整合包本身已带齐所需模组，若同时加载工坊订阅，可能出现模组错乱、无法进服或冲突。

进服前可采用任一做法：

- 关闭 Steam 后再打开整合包中的 `starbound.exe`
- 在 Steam 中退订全部 Starbound 创意工坊模组

## 首次设置

启动后可先打开游戏设置。与联机相关的两项建议开启：

- **通过 IP 进行多人游戏**
- **允许资源不匹配**

界面大小也可在设置中调整，见下文「界面缩放」。

## 创建角色

种族可按喜好选择，同时建议看一眼该种族自带的增益与减益。少数种族带有较特别的减益，创角前值得权衡。

角色名称建议自行填写并记住。联机时需要输入对方的角色名才能找到人，随机生成的名字不便于辨认和呼叫。

难度选项见下一节。创角完成后，按「服务器」一节加入本服。

## 难度

创建角色时可选择难度：

- **休闲（Casual）**：适合新手。不需要担心饿死，便于熟悉操作、模组与本服环境。
- **生存（Survival）**：适合已熟悉游戏的玩家。本服装有 **死亡不掉落** 模组，普通死亡不会掉落背包物品。若希望保留掉落惩罚，可自行移除该模组。
- **硬核（Hardcore）**：死亡会删档。本服一般不使用这一档。

不确定时可选休闲，之后再另建生存角色。

## 服务器

选好角色后，在多人游戏中加入服务器，填写如下信息：

| 项目 | 内容 |
| --- | --- |
| 地址 | `119.45.30.252` |
| 端口 | `21025` |
| 用户名 | 留空 |
| 密码 | 留空 |

若无法连接，可先核对地址与端口是否一致。

## 操作

### 前景与背景

世界分为前景与背景两层。

- 鼠标**左键**：铺设或挖掘前景
- 鼠标**右键**：铺设或挖掘背景

前景方块可以站立、踩踏。背景方块不能承重，但会透出光线；液体会沿背景流走，在部分特殊星球上则是沿背景流入。

### 常用按键

| 按键 | 作用 |
| --- | --- |
| WASD | 移动 |
| 空格 | 跳跃 |
| E | 交互 |
| I | 打开物品栏 |
| 1–6 | 选中快捷栏物品 |
| X | 在两套快捷物品栏之间切换 |
| Q | 丢弃手持物品 |

游戏有两套快捷物品栏，按 X 切换。若经常误触，可在按键设置中改掉。

Q 会把当前拿在手里的物品丢到地上。若担心误触丢掉贵重武器，同样可以改键。

## 界面缩放

默认界面有时会偏小。缩放路径：

**游戏设置 → Graphics → INTERFACE SCALE**

按阅读舒适程度调整即可。该项改动后，有时难以恢复到调整前的大小。

群内把这种情况称为「赛博灯泡」，借用「不要吞灯泡」的故事：有人劝阻仍去尝试，吞下去之后无法取出。INTERFACE SCALE 与此类似，贸然调到很大或调乱后，可能无法改回原来的界面。

## Linux / macOS

群文件中的默认整合包面向 Windows，启动文件为 `OpenStarbound/win/starbound.exe`。

Linux 与 Mac 需要对应系统的整合包，可私聊群主获取。启动方式以群主说明为准。服务器仍为 `119.45.30.252:21025`，用户名与密码留空。Steam 订阅、难度与界面缩放的说明与上文相同。

## 要点

- 使用群内 OpenStarbound 整合包，而不是 Steam 启动 Starbound。
- Windows：在 `OpenStarbound/win/` 中打开 `starbound.exe`。
- 关闭 Steam，或退订 Starbound 创意工坊模组。
- 设置中开启「通过 IP 进行多人游戏」和「允许资源不匹配」。
- 创角时留意种族自带效果，并自己填写角色名，便于联机呼叫。
- 新手可选休闲，老手可选生存；硬核会删档。
- 服务器 `119.45.30.252`，端口 `21025`；用户名、密码留空。
- 左键操作前景，右键操作背景；E 交互，I 物品栏，1–6 选物品。
- X 切换两套快捷栏，Q 丢弃手持物品；易误触时可改键。
- 界面偏小时可改 `INTERFACE SCALE`；该项可能无法恢复，群内称为赛博灯泡。
- Linux / Mac 向群主要对应系统的整合包。
