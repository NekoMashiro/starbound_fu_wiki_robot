Consumable Items / Summoning Items / Sakura Tribute

## Overview
The Sakura Tribute is an item that can be used to conjure the second boss of Arcana, Cosmo Nemesis. It can be crafted at an Academician's Table.

Note, the Sakura Tribute can only be used on an Animus planet.
