# [FU] Empty Batteries Sensor

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Empty_Batteries_Sensor

---

**Empty Batteries Sensor** can be used to automate fuel-based reactors (such as Combustion Generator or Fission Reactor) to stop burning fuel if the batteries still have plenty of charge.

It needs to be wired to the reactor (On/Off Input). It will find and check all batteries on this power conduit. Scan this sensor to see current status.
