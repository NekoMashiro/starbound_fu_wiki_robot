# [FU] Essentia Obscura

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Essentia_Obscura

---

**Essentia Obscura** is a liquid that inflicts Insanity on players who try to swim in it. This doesn't give any Madness currency.

It exists as puddles in Elder biomes, and some monsters pour this liquid when they are defeated. It can be obtained in unlimited quantities using Infinite mixing on Atropus Sea worlds and extracted for very useful resources (Note that this liquid can't be mixed in the environment, but only in a Liquid Mixer).

It is also an average fertilizer for Trays. Using it as fertilizer might be suboptimal, because its bonuses are exactly the same as those of Organic Soup, which is much easier to produce.
