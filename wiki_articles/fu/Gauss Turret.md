# [FU] Gauss Turret

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Gauss_Turret

---

The **Gauss Turret** is an object that can be built from the Power Station to improve defenses in an area.

The turret shoots explosives round like normal a Gauss Rifle would (Does not provide flashlight), and consumes its own energy to shoot projectiles.

- Input node is to activate the turret whenever a signal is sent into it. (Default/Empty leaves the turret active)
- Output node will send a signal whenever the turret detects an enemy.

## Tips
Note that the projectiles being shot out by this turret can be relatively slow, fast moving monster can potentially 'dodge' these projectiles.

Unlike the usual Defense Turret, it drops back itself when 'destroyed' instead of a Silicon Board and Copper Wire.

Like other turrets, it does not take in any standard damage, it can only be 'destroyed' when the tiles it is attached to gets removed/destroyed.
