# [FU] Hand Mill

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Hand_Mill

---

The **Hand Mill** is an early game extractor. It consumes most materials placed into it, and in exchange returns another, generally more useful resource. It doesn't require Power.

Not all materials are extractable, and some require more than one of the input material (e.g. 50 for most blocks).

Hand Mill does 1 extraction every 8.75 seconds. Later in the game it gets replaced by Extraction Lab, which produces exactly the same outputs (see **full list of extractions**), but is faster and has more slots.

## Tips
- If one Hand Mill is too slow, craft several of them. They will work simultaneously.
- If you place a Lab Directory near the Hand Mill, it will allow you to search "what is extracted from/into what" in-game.
- Hand Mill doesn't have wiring inputs/outputs (for Item Transference Devices), but you can place a Storage Bridge nearby, which will add them.
- Some blocks can be both extracted (in Hand Mill) and sifted/crushed, which will produce different materials.
