# [FU] Mechanic's Wrench

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Mechanic's_Wrench

---

**Mechanic's Wrench** is an early-game tool. It can connect wires without upgrading the Matter Manipulator.

Eventually you can add the wiring feature to the Matter Manipulator, but you'd need to spend 6 Manipulator Modules (3 on Paint mode, and then 3 on Wiring mode, which depends on Paint mode). These modules are rare/valuable, so in the early game you might want to save them for something else, like upgrading the Mining Laser, etc.
