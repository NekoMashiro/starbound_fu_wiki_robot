# [FU] Powder Sifter

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Powder_Sifter

---

**Powder Sifter** is a station that separates the powder-like blocks (like Sand, Loose Silt, Dirt, etc.) and returns any useful materials that are found inside. Most blocks cost 0 pixels, and the materials within them can be very valuable, so this is very beneficial to do.

Powder Sifter processes 1 block every 0.117 seconds. It is a faster and more efficient version of the early-game Sifter.
> *See the page Sifter for the list of blocks that can be sifted.*

Rock Breaker and Rock Crusher can process rock-like blocks in a similar manner.
