# [FU] Ship Component Racializer

**来源**: Frackin' Universe Wiki | **链接**: https://frackinuniverse.miraheze.org/wiki/Ship_Component_Racializer

---

**Racializer** is a station that gives you otherwise unobtainable race-specific ship furniture. For example, it can turn Apex Ship Door into Floran Ship Door (which is useful if your character is Apex and you can only craft Apex Ship Door, but you want to build a ship in Floran style).

## Supported items
Ship doors/hatches/lockers, FTL Fuel Hatch, Ship Teleporter, S.A.I.L Interface, Captain's Chair.

This should work with any race that has a furniture of needed type. If it doesn't have such furniture (for example, X'i barely have any furniture), then Racializer won't change anything.
