## Templates to quickly make an article
- - for articles like Bone-Steel Armor.
- - for articles like Kirhos.

Note that you don't need to manually add templates to articles about **items**, only the text (see [example](https://frackinuniverse.miraheze.org/w/index.php?title=Algae&type=revision&diff=36432&oldid=18687) from page Algae), because the bot already adds and (these templates are autopopulated with bot-collected data).

| Data Point (ie: Ice Resistance) |
| --- |

| 40% : Resist moderate cold |
| 60% : Resist extreme cold |
| 80% : Resist insane cold |
| 100% : Resist barbara streisand |
