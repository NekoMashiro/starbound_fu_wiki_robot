This hidden category contains pages with Template:Infobox item which weren't automatically categorized.

Possible reasons:
1. in-game typo in the category name,
1. the item is not categorized in-game or has a flavor category (e.g. Insane Notes have a category "Work of a Genius").
1. category= is valid but not yet supported by Template:Infobox item. Solution: edit Template:ItemPageCategory (or ask the admin if this template is protected) to add a more specific category to these pages.
